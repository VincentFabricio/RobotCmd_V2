# RoboCmd - control your robot motion

![img](.images/images.jpeg)

This repository contains a C++ progrma to command your robot with different motions. 

To correctly use this code the requirements are:
- A c++ compiler that support c++11 or later
- A posix-compliant system (like linux or camOS)

### Install dependencies

Open a terminal and run:

```bash 
$ sudo apt update
$ sudo apt install g++
```
Hallo

    $ sudo apt update
    $ sudo apt install g++

### Use this repository
Clone the repo:

    $ git clone ...

Compile the code:

    $ cd RobotCmd_v2
    $ mkdir build && cd build
    $ cmake ..
    $ make

Run the command:

    $ ./robot_cmd_seq
